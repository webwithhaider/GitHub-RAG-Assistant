# GitHub-RAG-Assistant

> Chat with any GitHub repository using AI.

An AI-powered GitHub repository assistant that uses **Retrieval-Augmented Generation (RAG)** to understand codebases, answer questions, explain project architecture, and provide context-aware responses with source code citations.

## ✨ Features

- 📂 Clone any public GitHub repository
- 🔍 Semantic code search
- 💬 Chat with source code
- 🧠 Retrieval-Augmented Generation (RAG)
- 📄 Source code citations
- 📁 Multi-language support
- ⚡ FastAPI backend
- 🎨 Next.js frontend
- 🗄️ Qdrant vector database


## 🛠 Tech Stack

| Layer | Technology |
|--------|------------|
| Backend | FastAPI |
| Frontend | Next.js |
| LLM | OpenAI / Gemini |
| Embeddings | BGE |
| Vector DB | Qdrant |
| Parser | Tree-sitter |
| Git | GitPython |
